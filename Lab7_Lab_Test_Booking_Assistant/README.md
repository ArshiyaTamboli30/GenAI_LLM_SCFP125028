# Lab Test Booking Assistant

An AI-powered lab test booking assistant built using Python, SQLite, LangChain, and Groq.

## Features
- View available diagnostic tests.
- Check available appointment slots.
- Book and cancel lab test appointments.
- Human approval before booking or cancellation.
- User-specific booking history.
- General medical information search.
- Email redaction and retry handling.
- Automated evaluation of assistant scenarios.

## Technologies
- Python
- SQLite
- LangChain
- Groq
- Kaggle Notebook
